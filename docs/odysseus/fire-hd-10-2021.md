# Runbook: Fire HD 10 (2021) as a Home Assistant kiosk, without root

The 2021 Fire HD 10 (11th gen, codename `maverick`, MediaTek MT8183, Fire OS 8 = Android 11, API 30)
has **no known bootloader unlock or root** (checked 2026-11; the community unlocks cover older Fire
models only). So there is no LineageOS here. This runbook keeps Fire OS and turns the tablet into a
kiosk by installing the app, making it the home app and switching Amazon's software off over adb.

> **Status: untested on a real tablet.** The commands are standard Android/Fire OS practice, not
> verified on `maverick`. Steps marked *(check)* depend on what your firmware allows. Fix this file
> with what you find. Never flash, fastboot or run "root" tools from the internet on this tablet.

What you get, and what you don't:

| | Fire HD 10 (no root) | Echo Show 5 ([echo-show-5.md](echo-show-5.md)) |
|---|---|---|
| Dashboard, home screen, Music, announcements | yes | yes |
| Wake word, Wyoming satellite, Sendspin | yes (mic quality: untested) | yes |
| Privacy-button key layout | not applicable (no such button) | yes (needs root) |
| Amazon removed from the system | no: disabled for the user only; comes back after a factory reset, and an OTA may re-enable some | n/a (LineageOS) |
| Boots straight into the app | yes if it is the only home app | yes |

## Rules for this job

- Use `adb -s $S` on every command; other devices may be attached.
- Dump the UI (`uiautomator dump`) before every tap; don't tap blind coordinates.
- Don't type passwords or tokens. Don't register the tablet to an Amazon account (see step 2).
- Ask the owner before the factory reset (step 1) and before the final reboot (step 8).
- Use the release-signed APK with the same `versionName` as the owner's other devices
  ([build.md](build.md)). Never install a debug build: Odysseus updates only install over the
  release key.

## 1. Start from a clean tablet (owner)

Best order, because a device owner can only be set on a device with no accounts (step 7):

1. Factory reset (Settings → Device options → Reset to factory defaults) if it has been used.
2. In the setup wizard, connect to Wi-Fi, then **skip** the Amazon sign-in (*Skip* / *Set up later*
   if offered). Some firmware insists on an account; if so, register one, and skip step 7.
3. **Turn off OTA updates before anything else** (step 2). Updates are the main thing that
   breaks this setup.
4. Developer options: Settings → Device options → tap **Serial number** 7×; then enable
   **Developer options → USB debugging** and accept the computer's RSA key on the tablet.

```sh
S=$(for s in $(adb devices | awk 'NR>1 && $2=="device"{print $1}'); do
      [ "$(adb -s $s shell getprop ro.product.device | tr -d '\r')" = maverick ] && echo $s; done | head -1)
P=com.msp1974.vacompanion.odysseus
a(){ adb -s $S shell "$@"; }
echo "serial=$S"; a 'getprop ro.product.model; getprop ro.build.version.release; getprop ro.build.version.sdk;
  getprop ro.build.version.fireos'
```

Expect Android 11 (SDK 30). Note the Fire OS version in your report.

## 2. Stop Amazon's updates

```sh
# Packages differ per firmware: list first, then disable what exists.
a pm list packages | grep -i -E 'otaupdates|systemupdates|dcp|ota'
a pm disable-user --user 0 com.amazon.device.software.ota 2>&1
a pm disable-user --user 0 com.amazon.device.software.ota.override 2>&1
a settings put global auto_time 1
```

Also turn off Settings → Device options → System updates → automatic updates if the menu is there.
Optional, at the router: block Amazon's OTA hosts for this tablet. Don't invent hostnames: take
them from the router's DNS log while the tablet checks for updates.

## 3. Install the satellite app

```sh
adb -s $S install -r "$APK"
a pm grant $P android.permission.RECORD_AUDIO
a pm grant $P android.permission.POST_NOTIFICATIONS 2>/dev/null || true
a appops set $P WRITE_SETTINGS allow
a appops set $P REQUEST_INSTALL_PACKAGES allow      # updates from Odysseus (updates.md)
a cmd notification allow_dnd $P
a dumpsys deviceidle whitelist +$P                    # no Doze
a appops set $P RUN_IN_BACKGROUND allow
a appops set $P RUN_ANY_IN_BACKGROUND allow
a dumpsys package $P | grep -E 'versionName|RECORD_AUDIO: granted'
```

Don't run `scripts/odysseus/setup_device.sh` as is: it aborts on `set -e` if a command fails
(`locksettings`, `set-home-activity`) and its privacy-button part needs root. Use the steps here.

## 4. Always-on screen

```sh
a settings put global stay_on_while_plugged_in 7      # screen on while charging (USB/AC/wireless)
a settings put secure screensaver_enabled 0
a settings put system screen_off_timeout 2147483647   # (check) some Fire OS builds ignore it on battery
a settings put system accelerometer_rotation 0; a settings put system user_rotation 1   # landscape
a locksettings set-disabled true 2>&1                 # (check) may be refused; set Lock screen to None in Settings
```

`user_rotation`: `1` is landscape for the tablet's normal orientation; use `0`/`1`/`3` to match
how it is mounted. The tablet must stay on its charger; for a wall mount a charge limit
(battery health) is out of scope here.

## 5. Make the app the home screen

The app's manifest already declares `HOME` + `DEFAULT` on `MainActivity` (so it can be the home app).
Fire OS hides the "default home app" setting, so:

```sh
a cmd package resolve-activity -c android.intent.category.HOME -a android.intent.action.MAIN | grep -m1 name=
a cmd package set-home-activity $P/com.msp1974.vacompanion.MainActivity 2>&1    # (check) may need more rights than shell has
```

If `set-home-activity` is refused, make ours the only home app by disabling Amazon's launcher:

```sh
a pm list packages | grep -i launcher                  # expect com.amazon.firelauncher
a pm disable-user --user 0 com.amazon.firelauncher
a input keyevent KEYCODE_HOME                          # should now open the satellite, or ask "which app"
```

Pick **Odysseus Echo → Always** if Android asks. Recover if you land on a black screen: the app is
still there, `a am start -n $P/com.msp1974.vacompanion.MainActivity`, or
`a pm enable com.amazon.firelauncher` to undo. Keep a USB cable and adb access until this works.

## 6. Switch off the Amazon extras (user 0 only, reversible)

Disable, never `pm uninstall` for all users or delete system files. Take names from
`pm list packages`; typical candidates (check each exists first):

```sh
for pkg in com.amazon.alexa.multimodal.gemini com.amazon.kindle com.amazon.avod com.amazon.venezia \
           com.amazon.recess com.amazon.dee.app com.amazon.imdb.tv.android.app com.amazon.shoptv.client; do
  a pm list packages | grep -q "package:$pkg$" && a pm disable-user --user 0 $pkg
done
a settings put global lockscreen_ads_enabled 0 2>&1 ; a settings put secure lock_screen_show_notifications 0 2>&1
```

Undo any of them: `pm enable --user 0 <pkg>`. Leave `com.amazon.device.*`, `com.amazon.cloud9`
(Silk), the system UI and framework packages alone: disabling those can bootloop a Fire tablet.
Hands-free Alexa ("Show Mode", wake word) would fight our microphone: turn **Alexa hands-free off**
in Settings → Alexa, and don't sign in to Amazon.

## 7. Kiosk lock (optional, stronger)

A **device owner** can pin the app (lock task) and stop others from opening. It only works on a
tablet with **no accounts at all** (no Amazon sign-in):

```sh
a dpm set-device-owner $P/com.msp1974.vacompanion.VACADeviceAdminReceiver 2>&1
```

If it says "already several accounts on the device", this step is not possible: skip it, steps
5–6 are enough. **Check first** that the app implements what you want from lock task (the app's
`VACADeviceAdminReceiver` exists, but it isn't a full kiosk-lock implementation). Without it,
rely on [Kiosk](kiosk.md): the app brings itself back after another app has been in front for the
chosen time.

## 8. First run, test, reboot

1. Start the app: `a am start -n $P/com.msp1974.vacompanion.MainActivity`. Handle the first-run
   screens like [new-echo-runbook.md](new-echo-runbook.md#5-first-run-screens-on-the-echo)
   (deny camera and media; continue with the default id). Phone setup: [setup.md](setup.md).
2. Smoke test for 2 minutes: same `pidof $P` before and after; `adb logcat -d | grep -E
   'AppExceptionHandler|Fatal signal'` is empty.
3. Ask the owner, then `adb -s $S reboot`; after 60 s, check that the app is in front and
   listening: `a dumpsys activity activities | grep -m1 mResumedActivity` should name `$P`.
4. In Settings → Experimental → Voice assistant, set the **Microphone calibration**, since the
   level compared between devices depends on the mic.

## 9. Known risks and checks

- **An OTA can undo this**: it may re-enable `com.amazon.firelauncher` or the apps from step 6. If
  the tablet shows Amazon's launcher after an update, repeat steps 5–6 and re-check step 2.
- **Mic and speaker quality**: the Fire HD 10 isn't a smart speaker; far-field wake word may be
  worse than on an Echo Show. Test wake word at 1 m and 3 m before mounting it.
- **Same build everywhere**: all devices must run the same app build ([wake word
  arbitration](../wake-word-arbitration.md)).
- **Updates through Odysseus** install over the release key only; Fire OS may show an "install
  unknown apps" prompt the first time (the `REQUEST_INSTALL_PACKAGES` appop above avoids it).

## Undo everything

```sh
a pm enable --user 0 com.amazon.firelauncher
a cmd package set-home-activity com.amazon.firelauncher/.launcher.FireHomeActivity 2>&1   # name from resolve-activity
a settings put global stay_on_while_plugged_in 0
adb -s $S uninstall $P
```

A factory reset restores the tablet completely.
